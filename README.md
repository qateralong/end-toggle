# End Toggle

Server-side Fabric mod: /end on|off opens or closes the End, and entities pass through End portals while it is closed.

## Features

- `/end on` and `/end off` open or close the End.
- While closed, entities pass through End portals.
- `/end status` and `/end reload`.

## Compatibility

Minecraft 1.21.1, Fabric Loader and Fabric API. Runs on the server; players need no client mod.

## Build

```bash
./gradlew build
```

The jar appears in `build/libs/`.
